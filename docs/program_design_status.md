# Programme design status

The theory of change links access to active account use, livelihood choices and resilience, with assumptions stated in the diagram. The logframe leaves district baselines and numeric targets open until districts are selected and a baseline is validated. The concept note uses five provisional UP candidates selected from an NFHS-5 four-indicator outcome rank: Shrawasti, Lalitpur, Bahraich, Balrampur and Sitapur. The ranking does not measure financial inclusion; field validation and boundary review must precede final district selection.

The bilingual XLSForm includes a consent gate and skip logic for account ownership, use, phone access, digital services, service barriers, decision control and desired support. Pyxform generated an XForm without warnings. Its optional ODK Validate check could not run because Java is absent from the available runtime.
