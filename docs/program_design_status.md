# Programme design status

The theory of change links access to active account use, livelihood choices and resilience, with assumptions stated in the diagram. The logframe leaves district baselines and numeric targets open until districts are selected and a baseline is validated. The concept note is a design draft; it does not assert that any specific UP districts are the lowest-performing because that ranking requires NFHS-5 and a reviewed crosswalk.

The bilingual XLSForm includes a consent gate and skip logic for account ownership, use, phone access, digital services, service barriers, decision control and desired support. Pyxform generated an XForm without warnings. Its optional ODK Validate check could not run because Java is absent from the available runtime.
