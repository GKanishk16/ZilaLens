# Deductive policy review codebook

| Code | Definition | Include when passage discusses |
|---|---|---|
| Access barriers | Constraints on obtaining or retaining an account/service | Documentation, distance, eligibility, connectivity, affordability |
| Usage barriers | Constraints on active, independent use | Dormancy, control, cash-out, fees, trust, agent availability |
| Digital access | Access, ability, and safety using mobile/digital channels | Phone ownership, digital literacy, authentication, fraud |
| Social norms | Household/community norms shaping women's agency | Mobility, control of money, gender roles, household permission |
| Program design | Rules and features of public schemes | Benefits, enrolment, incentives, grievance channels |
| Implementation capacity | Frontline and institutional delivery constraints | Staffing, training, monitoring, coordination, infrastructure |

No excerpts are represented as coded evidence until source documents are downloaded and page-checked. Any eventual workbook will use paraphrases shorter than 25 words and retain document and page identifiers.
