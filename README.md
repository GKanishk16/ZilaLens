# ZilaLens
## Women's Financial Inclusion and Empowerment Across Indian Districts, NFHS-4 (2015-16) to NFHS-5 (2019-21)

**Author:** Kanishk Gupta  
**About the Author:** Kanishk Gupta, PGDM (Research & Business Analytics), Lal Bahadur Shastri Institute of Management, Delhi — [GitHub](https://github.com/GKanishk16)

"Zila" is Hindi for district; ZilaLens views women's financial inclusion through a district lens.

ZilaLens is a reproducible research project designed to compare women's financial inclusion and related empowerment indicators across Indian districts. All findings are intended to come from public source files and are subject to survey and boundary limitations.

## Current data status

NFHS-4 and NFHS-5 district factsheets are now present and processed. Direct changes are calculated for four common indicators across name-matched districts after excluding changed/new geographies listed in Harvard Appendix A. The appendix does not provide a full parent crosswalk, so those areas are not imputed. The two factsheet sources do not include the requested bank-account-use or mobile-phone indicators; the finance-linked index remains unavailable. Source details and limits: [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) and [`data_quality_report.md`](data_quality_report.md).

## Key Findings

Current computed results (all source observations are survey estimates; changes are descriptive):

1. NFHS-4 and NFHS-5 provide **59,241** and **75,649** district-indicator rows respectively ([source files](data/raw/)).
2. Across **555 matched districts**, mean literacy increased **6.5 percentage points** ([change table](outputs/tables/district_changes.csv)).
3. Across the same matches, 10+ years of schooling rose **6.3 points**, early marriage fell **3.8 points**, and clean cooking fuel rose **15.9 points** ([change table](outputs/tables/district_changes.csv)).
4. The all-district Aspirational cohort literacy change difference was **+1.99 points** (95% bootstrap interval: **+0.76 to +3.14**); this is descriptive, not causal ([comparison table](outputs/tables/aspirational_comparison.csv)).
5. The five lowest UP districts on the available four-indicator mean-rank composite are **Shrawasti, Lalitpur, Bahraich, Balrampur, and Sitapur**; the composite does not measure financial inclusion ([UP ranking](outputs/tables/up_district_rankings.csv)).

District-change tables, the four-indicator typology, Aspirational District contrasts, and Uttar Pradesh NFHS-5 rankings are generated by `python run_all.py`. The UP mean-rank composite is descriptive and is not a financial inclusion index. See [`data_quality_report.md`](data_quality_report.md) for geography and missingness limits.

## Setup and run

Python 3.11 is the target runtime.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_all.py
```

## Repository guide

- `src/`: ingestion, harmonisation, and analysis code
- `data/raw/`: source files (large/raw files are not committed; download scripts and URLs are documented)
- `data/processed/`: tidy panel, crosswalk, and reviewed name overrides
- `docs/`: source register and qualitative codebook
- `outputs/`: tables, charts, maps, workbook, reports, and deck
- `tests/`: pipeline tests

Raw files over 50 MB must not be committed. Keep them reproducible through source links/download scripts. Never commit API keys or tokens. Data belongs to IIPS/MoHFW NFHS, data.gov.in, and NITI Aayog; the MIT licence covers code only.
